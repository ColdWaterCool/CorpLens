# Contributing

Issues and pull requests are welcome.

## Before opening a PR

1. Keep API keys and real customer data out of the repo (use `.env` locally only).
2. Run `python scripts/check_repo_secrets.py` if you touched config or docs.
3. Prefer small, focused changes with a short description of *why*.

## Local demo

```powershell
.\start.bat
```

Default mock mode works without an API key.
