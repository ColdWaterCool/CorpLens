# CorpLens 辩证思考流（通用 Skill · 无行业案例名）

> 嵌入各席分析。禁止在对用户可见输出中出现具体内部案例店名或未公开工艺细节；只复用**思考结构**。

## 目标
把「转型」做成可辩驳、可试验、可排序的 SOP，而不是流水账罗列。

## 1. 优化点四象限（先排序再方案）
提出数字化方案前，先判断优化点落在哪一类（可多选，必须排序）：
1. **人力资源**：编制、教育水平、老龄化、凝聚力；培训 vs 换班底 vs 自动化
2. **品牌渠道**：商标/Logo/IP、地方特色、传播路径、平台导流、新触点
3. **产品 / 服务创新**：个性化 vs 标准化、品质一致性、人工 vs 设备/工具对比实验
4. **平台化战略**：官网/小程序、对外 SOP、知识能否沉淀、运维成本

## 2. 人力资源辩驳链
- 人数、教育/岗位结构、核心熟练者占比是否可知？
- 若低技能岗位占主导：是「没有流程可走」吗？先建 SOP 还是先换人？
- 换班底 → 凝聚力与产品力风险、成本上升
- 替代：培训？提福利留人？工具/自动化减负？
- **实验题**：自动化/辅助工具与纯人工的效果是否等价？必须小范围对比，禁止直接下结论

## 3. 品牌渠道辩驳链
- 商标后是否有统一视觉？是否形成可传播的社区/社群 IP？
- 能否结合**当地特色**做差异，而不是做成同质平台店？
- 上平台/外卖：人手不足时是否会爆单？如何限时、限量、调班？
- 新触点（自助点位、联名、周边导流）是否值得试点？监管与体验门槛？

## 4. 平台化战略辩驳链
- 有无统一入口与对外说明？有无对内 SOP？
- 关键 Know-how 是否只在少数核心人员脑中？如何传承且不稀释信任？
- 数字化是强化 Brand Effect，还是把品牌做成可替换的流量店？
- **运维成本**：内容维护、SaaS/抽成、客服差评、合规巡检——算不清就暂缓自建重系统

## 5. 品牌 / 技术 / 创新力加权根因
对有积淀的企业，核心分析围绕：
- **品牌 Brand Effect**（信任、地方记忆、老客资产）
- **技术**（工艺/服务可复制性、标准化）
- **创新力**（产品、渠道、组织）
用：`薄弱贡献 = 权重 × (100 − 强度)`，权重之和为 1；最高薄弱项优先作为 SOP 切入。

## 6. 经济席：调查 + PEC
- 先用调查口径：人数、薪资高低（推均值）、编制结构；成本展开写，禁止一句带过
- **PEC**：政策关注点（待核验）/ 市场结构 / 地方好感与消费文化
- 比例与指数一律标注「推断」，用于排序而非财务承诺

## 7. 流程图：思考化
禁止「问题A→问题B→问题C」抱怨链。
必须含：真实作业链、决策菱形、试点/实验支路、守住卖点的目标链、失败回退或风险回流。

## 8. 优先级
行动必须给出 **P0–P3**：
- P0：不做则卖点/合规立即受损
- P1：90 天内必推
- P2：可试点，受 P0/P1 约束
- P3：以后再说（含重平台与高运维项）
