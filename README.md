# 企析智体 CorpLens

**把企业转型需求，做成可辩论、可试验、可排序的分析书。**

CorpLens（CorpShift × FirmLens）是一套本地可跑的**企业转型需求分析智能体**：  
填一份结构化调查 → 四席并行分析 → 输出可下载的《转型需求分析书》（含流程图与效益示意）。

---

## 解决什么问题

数字化 / AI 转型咨询常见两种翻车：

1. **流水账方案**：功能清单一大堆，不知道先做什么、为什么做  
2. **黑盒结论**：直接给「上小程序 / 上平台」，缺少辩驳与小范围试验

CorpLens 把分析过程拆成可见的多席位，并嵌入统一的**辩证思考流 Skill**，先排序优化点，再谈方案。

---

## 核心思想

| 原则 | 含义 |
|------|------|
| **多席可见** | 市场切入 · 经济效益 · 实现创新 · 流程图，并行产出、可对照 |
| **先排序再方案** | 人力 / 品牌渠道 / 产品服务 / 平台化 四象限排序后，再写 P0–P3 |
| **可辩驳、可试验** | 每个关键判断附带反例与小范围对比实验，禁止一锤定音 |
| **方法公开、案例分离** | 思考结构开源；内部行业案例名不进公开输出与演示模板 |

公开演示默认用「社区宠物洗护」示意，**与任何内部真实案例解耦**。

---

## 主要能力

1. **结构化调查** — 企业名与现状自由填写，其余以单选 / 多选降低空话  
2. **四席分析** — 市场 / 经济 / 实现 / 流程并行，过程可看  
3. **需求分析书** — 自动组装可下载 Markdown（标题、优先级、流程图）  
4. **可视化** — 关键词圈、加权根因、Mermaid 流程、效益示意柱图  
5. **API 接入** — 首页配置 OpenAI 兼容接口；Key 只存本机 `.env`  
6. **示意模式** — 无 Key 也可一键生成演示稿，便于试用与截图

---

## 思考流如何保护「方法」又不必开「私有包」

独特辩驳思考已沉淀为通用 Skill：

```text
prompts/skills/corplens_dialectic.md
```

- 各席分析会**自动嵌入**该 Skill  
- 对用户可见输出中**不出现**内部行业案例名  
- 公开演示模板为「社区宠物洗护」，与内部案例分离  

也就是说：**开源的是思考结构与产品骨架，不是某家真实客户的私有材料。**

## 技术栈

| 部分 | 技术 |
|------|------|
| 界面 | Streamlit |
| 语言 | Python 3.10+ |
| 模型 | OpenAI 兼容 API（默认可接 SiliconFlow 等） |

```text
CorpLens/

├── start.bat              # Windows 一键启动
├── prompts/

│   └── skills/            # 辩证思考流 Skill
├── src/                   # 流水线、组装、可视化

├── scripts/               # 密钥扫描、连通性探测
├── .env.example           # 环境变量模板（无真实 Key）
└── README.md
```

## 快速开始

需要：Python 3.10+（首次运行会自动建 `.venv` 并装依赖）。

```powershell
.\start.bat
```

1. 浏览器打开 Streamlit 页面  
2. （可选）在首页填写 API Key → 保存到本机 `.env`，关闭示意模式  
3. 或直接点 **一键生成演示**，查看完整需求分析书  

配置模板见 `.env.example`：

```env
TRANSFORM_AGENT_MOCK=1
LLM_PROVIDER=siliconflow
OPENAI_API_KEY=
OPENAI_MODEL=Qwen/Qwen2.5-14B-Instruct
```

公开前建议运行：

```powershell
python scripts/check_repo_secrets.py
```
